# RemotePostgresInstaller

Скрипт на Python для удалённой установки и настройки PostgreSQL через SSH на сервере под управлением Debian, AlmaLinux, CentOS, Ubuntu и других систем. Выбирает сервер с наименьшей загрузкой и настраивает PostgreSQL для удалённых подключений.

## Особенности

- Установка PostgreSQL в зависимости от дистрибутива
- Настройка внешних подключений (listen_addresses, pg_hba.conf)
- Создание пользователя `student` с паролем
- Проверка соединения с БД после настройки
- Поддержка подключения по SSH с ключом
- Логирование выполнения и ошибок (логи пишутся в консоль, кроме того, лог SSH-подключения сохраняется в файл)
- Автоматический выбор наименее загруженного сервера

## Требования

- Python 3.8+
- Доступ к серверам по SSH с использованием ключа
- Установленные библиотеки из `requirements.txt`

⚙️ Использование

- Клонируйте репозиторий
- Установите зависимости
  pip install -r requirements.txt
- Запуск скрипта производится командой, в которую строкой через запятую без пробела передаются IP-адреса целевых серверов
  python install_postgres.py <ip1,ip2>

🔐 SSH

В __main__ укажите значения имени пользователя и путь к ssh-ключу на вашем компьютере:
username = "root"
ssh_key_path = "/путь/к/ssh_ключу"

📌 Примечания

    В скрипте используется пароль 'your_password' для пользователя student. Замените его на безопасный в объявлении метода:
     def check_postgres_connection(self, host, user='student', password='your_password', dbname='postgres', port=5432)
    

    По умолчанию разрешён доступ с IP 192.168.1.42. При необходимости отредактируйте строку, указав IP-адрес, с которого будет осуществляться доступ к базе данных:
    "host all student 192.168.1.42/32 md5"

## ❓ Вопросы и принятые решения

В процессе разработки и настройки проекта возникли следующие вопросы, которые потребовали дополнительных решений:

### 1. **Выбор пакета для работы с SSH**
   - **Вопрос**: Какой пакет выбрать для работы с SSH-соединениями на Python?
   - **Решение**: Был выбран пакет **paramiko**, так как он является одним из самых популярных и стабильных решений для работы с SSH. Он позволяет безопасно подключаться к удалённым серверам, выполнять команды и работать с файлами через SFTP. Кроме того, paramiko поддерживает работу с SSH-ключами, что является важным для безопасности в автоматизированных системах.

### 2. **Поддержка разных операционных систем**
   - **Вопрос**: Как правильно настроить PostgreSQL на различных операционных системах (например, Debian, Ubuntu, Almalinux)?
   - **Решение**: Для решения этой задачи была реализована функция, которая определяет операционную систему с помощью команды `grep` и затем выполняет соответствующие команды установки и настройки PostgreSQL для каждой из поддерживаемых ОС. Это позволяет унифицировать процесс настройки на разных серверах и избежать ошибок, связанных с неверным выбором команды для установки.

### 3. **Обработка ошибок выполнения команд**
   - **Вопрос**: Как правильно обработать возможные ошибки при выполнении команд на удалённых серверах?
   - **Решение**: В проекте реализована система обработки ошибок через проверку кода возврата каждой команды и анализ вывода ошибок через стандартный поток `stderr`. В случае ошибки выполнение команды записывается в лог и возвращается пользователю, что позволяет оперативно устранять проблемы.

### 4. **Безопасность подключения**
   - **Вопрос**: Как обеспечить безопасность при подключении к удалённым серверам?
   - **Решение**: Для повышения безопасности подключения используется метод аутентификации по SSH-ключу, а не по паролю. Это позволяет исключить угрозу перехвата пароля и повысить уровень защиты.

### 5. **Тестирование кода**
   - **Вопрос**: Как протестировать работу SSH-соединений и выполнения команд?
   - **Решение**: Для тестирования был использован модуль **unittest**. Моки и фикстуры позволяют проверять корректность выполнения команд, без необходимости подключения к реальным серверам, что ускоряет процесс тестирования и уменьшает зависимость от внешних факторов.
